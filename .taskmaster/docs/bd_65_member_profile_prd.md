# Overview
BD-65 마이페이지 프로필 UI 재구성. 기존 마이페이지(`/me`)는 프로필 카드·로그아웃·회원탈퇴가 단일 페이지에 혼재된 구조였다. 와이어프레임 기반으로 다음 문제를 해결한다:
1. 데스크톱 GNB(사이드바)에 로그아웃 버튼이 없어 마이페이지까지 이동해야 했음
2. 모바일에서 GNB가 BottomNav로 대체되므로 로그아웃 접근성이 낮았음
3. 섹션 구분 없이 기능이 나열되어 있어 시각적 위계가 불명확했음

핵심 출처
- 사용자 제공 와이어프레임 이미지 (2026-06-04): 프로필 정보 + 주간 시간표 + 계정 탈퇴 3-섹션 구성
- 기존 구현: `src/app/(main)/me/MeContent.client.tsx`, `src/components/layout/sidebar.tsx`

# Goals
1. **사이드바 로그아웃**: 데스크톱(lg+)에서 사이드바 하단 유저 영역에 로그아웃 버튼 추가. 마이페이지 방문 없이 즉시 로그아웃 가능.
2. **프로필 정보 섹션 분리**: "프로필 정보" 섹션 헤더 + "프로필 정보 수정" 버튼을 헤더 우측에 배치.
3. **모바일 로그아웃**: lg 미만에서 사이드바가 숨겨지므로 마이페이지 내 `lg:hidden` 로그아웃 카드 추가.
4. **계정 탈퇴 섹션 재구성**: 경고 텍스트 + "회원 탈퇴" 버튼을 인라인(좌우 배치)으로 재구성.

# Non-goals
- 주간 시간표(스케줄 캘린더) — 별도 태스크로 분리
- 프로필 이미지 업로드 로직 변경 없음
- 비밀번호 변경 UI 변경 없음

# Audience & UX context
- 다크 테마 고정
- 모바일(360px~) / 데스크톱(lg 960px+) 동시 지원
- 로그아웃은 자주 쓰이는 동작이므로 GNB에서 바로 접근 가능해야 함

# Existing architecture (재사용 대상)
- `src/app/(main)/me/MeContent.client.tsx` — 마이페이지 콘텐츠 (전면 재구성)
- `src/components/layout/sidebar.tsx` — 데스크톱 GNB (로그아웃 버튼 추가)
- `src/domain/auth/hooks/useLogout.ts` — 로그아웃 훅 (재사용)
- `src/components/ui/{Card, Button, Dialog}` — UI 프리미티브 (재사용)

# Scope

## Task 1 — 마이페이지 프로필 UI 재구성

### 1.1 프로필 섹션 헤더 분리
- `MeContent`에 `<section>` 래퍼 + `<h2>프로필 정보</h2>` 헤더 추가
- 헤더 우측에 "프로필 정보 수정" 버튼 배치 (`isEditing` 상태일 때 숨김)
- 프로필 카드에서 기존 "정보 수정" 버튼, "비밀번호 변경" 링크, Badge 제거

### 1.2 모바일 전용 로그아웃 섹션
- `<section className="lg:hidden">` 안에 로그아웃 카드 추가
- 데스크톱에서는 `lg:hidden`으로 숨김 처리 (사이드바 로그아웃과 중복 방지)

### 1.3 계정 탈퇴 섹션 인라인 재구성
- "계정 탈퇴" `<h2>` 섹션 헤더 추가
- 기존 Card에서 로그아웃 버튼 제거, 탈퇴 버튼만 인라인 우측 정렬
- 경고 텍스트(좌) + "회원 탈퇴" 버튼(우) flex 레이아웃

### 1.4 사이드바 GNB 로그아웃 버튼
- `sidebar.tsx`에 `useLogout`, `useRouter`, `useToast` 추가
- 하단 유저 링크 아래 로그아웃 버튼 추가 (nav 아이템과 동일 스타일)
- `LogOut` 아이콘 + "로그아웃" 텍스트, pending 시 disabled

# Test Strategy
- 데스크톱(lg+): 사이드바 하단에 로그아웃 버튼 표시, 마이페이지 내 로그아웃 버튼 미표시
- 모바일(lg 미만): 마이페이지 내 로그아웃 버튼 표시, 사이드바 미표시
- 로그아웃 클릭 → 토스트 → `/login` 리다이렉트
- 회원 탈퇴 클릭 → 확인 다이얼로그 → 탈퇴하기 → 토스트 → `/login` 리다이렉트
- "프로필 정보 수정" 클릭 → 편집 폼 표시, 취소 → 뷰 복귀
