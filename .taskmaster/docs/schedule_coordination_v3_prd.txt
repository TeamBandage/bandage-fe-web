# 합주 일정 조율 v3 + 선곡 회의 UX 개선 PRD

## Overview

선곡 회의 / 합주 일정 조율 v2 까지 구현된 UI 를 기반으로, 실제 사용 흐름에서 드러난 두 가지 큰 결함을 정리한다.

1. **선곡 회의 탭**: 키보드 방향키로 곡을 이동할 때, 포커스된 곡이 화면 밖으로 사라져 위치를 잃어버린다.
2. **합주 일정 조율 탭**: 현재는 "합주 시간표 생성" 탭과 "매트릭스" 탭이 완전히 분리되어 있어, 매트릭스가 단순히 별도의 화면으로 동작한다. 매트릭스는 본래 *전체 선곡 기간을 한눈에 파악하기 위한 보조 뷰* 로서, 주차별 시간표 UI 와 강하게 결합되어야 한다. 또한 매트릭스의 가용 시간 표기는 곡별 멤버 구성을 반영하지 않은 채 "전체 멤버 합집합" 만을 보여주고 있어 실제 의사결정에 도움이 되지 않는다.

이 PRD 는 위 두 영역을 아래 목표에 맞게 재구성한다.

- 선곡 회의: 방향키 이동 시 자동 스크롤 보장
- 합주 일정 조율: 주차별 UI ↔ 매트릭스 통합, 곡별 가용시간, 주차 단위 복사/반복, 색상 명도 개선

## Goals

- **G1 (선곡)**: 방향키로 곡을 이동할 때, 포커스된 곡이 항상 보이도록 부드러운 자동 스크롤이 동작한다.
- **G2 (통합)**: "합주 시간표 생성" 탭 안에서 토글 하나로 *주차별 UI ↔ 매트릭스* 를 전환한다. 좌측 추천안 / 우측 가능·불가능 멤버 패널 & 합주 블럭 리스트 패널은 두 뷰에 공통 고정.
- **G3 (주차 가독성)**: 매트릭스에서 주 단위 경계가 시각적으로 명확하게 구분된다. 좌측에 주차 라벨이 노출되고, 라벨 클릭 시 해당 주차의 주차별 UI 로 즉시 전환된다.
- **G4 (곡별 가용시간)**: 매트릭스 / 주차별 UI 모두에서, 우측 합주 블럭 패널의 특정 블럭을 선택하면 해당 곡 참여 멤버 기준의 가용시간으로 히트맵이 갱신된다. 다시 클릭하면 전체 멤버 기준으로 복귀.
- **G5 (블럭 편집 일관성)**: 합주 블럭 메타 정보(곡, 길이, 메모 등) 수정은 주차별 UI 와 매트릭스 어디서나 동일하게 수행 가능.
- **G6 (시간 범위 동기화)**: 매트릭스의 슬롯 범위는 주차별 UI 의 표출 시간 설정(예: 09–22, 24h)과 항상 일치한다.
- **G7 (주별 반복/복제)**: 매트릭스에서 한 주를 선택해 *전체 주차 일괄 적용* 또는 *원하는 주차에만 선택적 적용* 을 할 수 있다. 자동 시간표 생성은 현재 선택된 주차에만 적용.
- **G8 (역할 분리)**: 세부 슬롯 배치 = 주차별 UI, 주 단위 반복 정책 = 매트릭스 — 책임이 명확히 갈린다.
- **G9 (색상 명도)**: 매트릭스 히트맵 단계 간 명도 차이를 강화해 한눈에 비교 가능.
- **G10 (호버 기반 인원 패널)**: 매트릭스 / 주차별 UI 의 임의 셀(또는 슬롯)에 마우스를 올리기만 해도 우측 "가능/불가능 인원" 패널이 해당 (일자, 슬롯) 기준으로 즉시 갱신된다. 클릭/선택 없이 호버만으로 동작.

## Non-goals

- 선곡 회의의 다른 인터랙션(드래그 정렬, 라이브 동기화 등)은 변경 범위 밖.
- 매트릭스에서 직접 새 합주 블럭을 페인트로 생성하는 기능은 본 버전에서 제외 — 블럭 생성은 주차별 UI 에서만.
- 멀티 셀렉트 / 일괄 메타 편집 등 고급 편집 기능은 후속.

## Domain 1. 선곡 회의 — 키보드 포커스 자동 스크롤

### 현 상태
- 곡 리스트는 가상화 없이 일반 스크롤 컨테이너 안에 렌더된다.
- 방향키(ArrowUp / ArrowDown)로 selectedIndex 가 이동하지만, 포커스된 항목이 뷰포트 밖으로 나가면 사용자가 따라가기 어렵다.

### 요구사항
- 선택된 곡 항목에 `data-song-id` 또는 ref 를 달고, selectedIndex 변경 effect 에서 `element.scrollIntoView({ block: 'nearest', behavior: 'smooth' })` 호출.
- 첫 진입 / 마운트 직후의 초기 스크롤은 발생하지 않아야 함(점프 방지). 사용자의 키 입력으로 인한 변경에서만 스크롤.
- 마우스 클릭으로 선택을 바꾼 경우는 이미 보이는 항목이므로 스크롤 호출이 no-op 이지만 호출은 무방.
- 가상 리스트가 아닌 일반 DOM 가정. 컨테이너의 overflow 가 `auto` 인 경우만 동작 — `block: 'nearest'` 가 부모 스크롤 영역 자동 탐지.

### 구현 포인트
- `src/domain/setlist-meeting/components/SongListPanel*.tsx` (실제 파일은 코드베이스 확인 후 결정)
- 선택된 항목 ref 를 Map<string, HTMLElement> 로 보관하거나, 매 렌더 시 `useRef` + `useEffect([selectedSongId])` 에서 querySelector.

## Domain 2. 합주 일정 조율 — 주차별 UI / 매트릭스 통합

### 2-1. 진입 통합

- 현재의 별도 "매트릭스" 탭은 "합주 시간표 생성" 탭 내부의 *뷰 토글* 로 흡수된다. 상단 탭은 줄어들고, 시간표 생성 탭 헤더에 `[주차별 | 매트릭스]` 토글 추가.
- 좌측 추천안 패널, 우측 가능·불가능 멤버 패널은 두 뷰에 공통으로 고정 표출.
- 우측 합주 블럭(드래그 풀) 패널은 *주차별 UI 에서만* 좌측에서 슬라이드되어 노출. 매트릭스 뷰로 전환되면 부드럽게 하단(또는 우측)으로 collapse / 다른 위치로 이동하고, 그 자리에 가능·불가능 멤버 패널이 들어선다.
  - 단순화 안: 좌측에는 합주 블럭 풀, 우측에는 가능·불가능 멤버 패널을 두 뷰 공통으로 고정. 토글에 따라 가운데 본문만 바뀐다. 구현 단계에서 둘 중 더 간결한 안 채택.

### 2-2. 매트릭스 — 주 단위 가독성

- 행은 일자 × 슬롯, 열은 멤버가 아니라 동일하게 *일자 시퀀스* 유지. (현행과 동일)
- 주(월–일) 경계마다 굵은 보더 / 또는 1행짜리 spacer 로 시각적 분리.
- 좌측 첫 컬럼에 `W14`, `W15` 처럼 주차 라벨 + 해당 주의 첫날 라벨. 클릭 시 → 주차별 UI 로 토글 + 해당 주로 jump.
- 슬롯 시간 범위는 주차별 UI 의 표출 시간 설정 store 를 그대로 참조.

### 2-3. 곡별 가용시간 모드

- 우측 합주 블럭 풀의 *특정 블럭* 을 클릭하면 매트릭스/주차별 UI 의 히트맵이 그 곡 참여 멤버 기준으로 재계산.
  - 강조: 선택된 블럭 카드에 `ring` 등 활성 표시.
  - 다시 같은 블럭 클릭 → 전체 멤버 기준으로 복귀.
  - 다른 블럭 클릭 → 그 곡 기준으로 즉시 전환.
- 헤드 영역에 `현재 모드: 전체 멤버 / {곡 제목}` 라벨.
- 곡 ↔ 멤버 매핑은 setlist 도메인의 곡 메타에서 가져옴 (`participantMemberIds: string[]`).

### 2-4. 블럭 메타 편집

- 매트릭스 셀에 박힌 lock(=배치된 합주 블럭) 을 클릭하면 주차별 UI 에서와 동일한 편집 다이얼로그/패널 열림 (곡 변경, 길이 변경, 메모, 삭제).
- 길이 변경 시 기존 reflow 로직(`reflowMatrixLocks`) 그대로 사용.

### 2-5. 주별 반복 / 복제

- 매트릭스 본문 위 액션바에 두 개 버튼:
  - **모든 주차에 적용**: 현재 *기준 주* 의 lock 들을 모든 다른 주차에 동일 요일·슬롯으로 복사. 충돌 시 해당 주차의 기존 lock 은 reflow.
  - **주별 일정 반복** (선택적 복사): 클릭하면 매트릭스가 "주차 선택 모드" 로 진입. 다른 주차들이 하이라이트되고, 사용자가 *기준 주 → 적용 대상 주차들* 을 클릭으로 추가/제거. `copy & paste` 버튼으로 확정. 선택한 주차에만 복사.
- 기준 주는 사용자가 명시적으로 선택. (좌측 주차 라벨에 "기준" 라디오 또는 long-press)
- 충돌 처리: 기존 lock 은 동일 일자 내에서 forward 우선 reflow. 자리 없으면 다음 일자.

### 2-6. 자동 시간표 생성 스코프

- 주차별 UI 의 `자동 시간표 생성` 버튼은 *현재 선택된 주차* 의 일자 범위에 한정. 결과적으로 다른 주에 영향이 없도록 알고리즘 입력 범위 축소.

### 2-7. 호버 기반 가능/불가능 인원 패널

- 매트릭스/주차별 UI 의 셀에 마우스를 올리면(`pointerenter`), 우측 "가능/불가능 인원" 패널이 해당 (date, slot) 기준으로 즉시 갱신.
- 호버 떼면(`pointerleave` 컨테이너 단위) 마지막 호버 상태 유지(깜빡임 방지). 패널 헤더에 "기준: 04-29(수) 19:30" 식의 라벨 노출.
- 곡별 가용시간 모드(특정 블럭 선택)일 때는, 인원 패널도 그 곡의 참여 멤버 한정으로 가능/불가능 분류.
- 호버 갱신은 throttle(예: 50ms) 또는 rAF 로 과도한 리렌더 방지.
- 매트릭스에서는 lock 위에 호버 시 lock 의 시작 슬롯을 기준으로 사용.
- 모바일/터치는 호버가 없으므로 클릭으로 동일 갱신.

### 2-8. 색상 명도

- 단색 초록 5단계 → 4단계로 줄이되 명도 격차 확대. 예시:
  - 0% → `bg-card`
  - <33% → `bg-success/20`
  - <66% → `bg-success/45`
  - <100% → `bg-success/75`
  - 100% → `bg-success`
- 범례도 동일 단계로.

## Data / Store 변경

- `useScheduleView` (혹은 동등 store):
  - `mode: 'weekly' | 'matrix'` 추가
  - `selectedWeekStart: string` (월요일 ISO)
  - `focusedSongBlockId: string | null` — 곡별 가용시간 모드용
  - `hoveredCell: { date: string; slot: number } | null` — 호버 기반 인원 패널 갱신용
  - `repeatBaseWeekStart: string | null`, `repeatTargetWeekStarts: string[]` — 주별 복제 모드 상태
- `matrixLockStore`: 주차 식별자(weekStart) 를 별도 필드로 보관할지, 단순히 `date` 에서 파생할지는 구현 시 결정. 파생이 우선.

## Utility 변경

- `coverageHeatmap(meetingId, songId | 'ALL')` 형태의 셀렉터 추가 — 곡별 멤버 합집합 가용시간 계산.
- `copyWeekLocks(srcWeekStart, targetWeekStarts[])` — 주별 복사 + reflow 통합 유틸.

## Acceptance Criteria

1. 선곡 회의에서 ArrowDown 을 길게 누르면 포커스된 곡이 항상 뷰포트 안에서 보인다.
2. "합주 시간표 생성" 탭 헤더에 `[주차별 | 매트릭스]` 토글이 존재하며, 별도의 "매트릭스" 탭은 사라졌다.
3. 매트릭스에서 좌측 주차 라벨을 클릭하면 주차별 UI 로 전환되며 해당 주가 선택된다.
4. 우측 패널의 합주 블럭을 한 번 클릭하면 두 뷰의 히트맵이 곡 참여 멤버 기준으로 재계산되고, 한 번 더 클릭하면 전체 멤버 기준으로 복귀한다.
5. 매트릭스의 lock 을 클릭하면 주차별 UI 와 동일한 편집 UI 가 열려 곡/길이/메모를 수정할 수 있다.
6. 주차별 UI 에서 표출 시간을 09–24 로 바꾸면 매트릭스의 행 범위도 즉시 동일해진다.
7. 매트릭스 액션바의 "모든 주차에 적용" 클릭 시 기준 주의 lock 이 다른 모든 주차에 복제되고, 충돌은 reflow 로 해결된다.
8. "주별 일정 반복" 클릭 → 주차 선택 → "copy & paste" 흐름이 동작하고, 선택한 주차에만 복사된다.
9. 자동 시간표 생성은 현재 선택된 주차에만 새 lock 을 추가한다 (다른 주의 lock 은 변경 없음).
10. 매트릭스 색 단계가 사람 눈으로 구분 가능한 수준의 명도 격차를 갖는다.
11. 주(월–일) 경계가 매트릭스에서 시각적으로 명확하다.
12. 매트릭스/주차별 UI 의 셀에 마우스를 올리는 것만으로 우측 가능/불가능 인원 패널이 그 (일자, 슬롯) 기준으로 즉시 갱신된다.
13. 곡별 가용시간 모드에서는 호버 시 인원 패널이 해당 곡 참여 멤버 한정으로 표시된다.

## Out of Scope

- 매트릭스에서 직접 lock 신규 생성 (드래그 페인트)
- 멤버 단위 가용시간 직접 편집 모드를 매트릭스에서 제공
- 곡-멤버 매핑 편집 UI (선곡 회의에 이미 존재한다고 가정)

## 구현 순서 제안

1. 셀렉터 분리: `coverageHeatmap(songId | 'ALL')` 추출 + 기존 매트릭스가 사용하도록 리팩터.
2. `useScheduleView` 에 `mode`, `selectedWeekStart`, `focusedSongBlockId` 추가.
3. "매트릭스" 별도 탭 제거 → "합주 시간표 생성" 탭 내부 토글.
